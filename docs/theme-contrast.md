# Theme contrast audit

Each theme has four palette colours plus an independent text colour. Body text meets 4.5:1 contrast against its background except 808s & Heartbreak, which intentionally matches the supplied album cover lettering. Existing readable primary text colours are retained; other themes use black or white. MyCP preserves its original white, green, dark green and pink palette with black body text. Control labels can also use the text colour for contrast. phi retains its original CSS styling.
